## Read-Only Variable Inventory

`ai variable.properties` enumerates variables in inspectable package and nested executable scopes and returns both variable and scope native IDs. The native fixture asserts package and task-scope discovery. Scope-read or ownership failures are reported as incomplete coverage; discovery does not enable nested-scope mutation. Sensitivity remains `Unclassified`, and values and expression text remain omitted. Evidence: [VerifyVariableProperties](tests/SsisAiRuntime.Ssis16IntegrationTests/Program.cs#L376) and [PackageVariableInspector](src/SsisAiRuntime.Ssis16/PackageVariableInspector.cs).

The assignment collection's COM enumerator throws on this SSIS 16 host despite nonzero `Count`; the adapter uses the documented typed indexer and the native fixture verifies save/reload projection. The native fixture uses synthetic supplied inventory, not a loaded `.dtproj`; project discovery, candidate-list projection, CLI project-graph exposure, and native project-backed verification remain open. Evidence: [ProjectInventory](src/SsisAiRuntime.Inspectors/ProjectInventory.cs), [PackageParameterBindingGraphBuilder](src/SsisAiRuntime.Inspectors/PackageParameterBindingGraphBuilder.cs), [ProjectDependencyGraphBuilder](src/SsisAiRuntime.Inspectors/ProjectDependencyGraphBuilder.cs), [Execute Package target coverage probe](tests/SsisAiRuntime.Ssis16IntegrationTests/Program.cs), [binding tests](tests/SsisAiRuntime.Tests/PackageParameterBindingGraphTests.cs), and [project graph tests](tests/SsisAiRuntime.Tests/ProjectDependencyGraphTests.cs).
